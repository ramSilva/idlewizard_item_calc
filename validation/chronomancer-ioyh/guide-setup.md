## 5. Phases

== Phases ==

A typical run consists of

* Level Pet (Be able to still cast Time Fork)
* Stack Spells 
* Pet Levelling phase (As much as possible so you can no longer cast TF)
* Skip Time
* Void Mana Phase 
* Quick Burst Phase to get upgrades and sources.
